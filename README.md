# 《账本城》· 三章短篇与 IP 设定集

课堂虚构作品的一次完整「小说工程」实践：从世界观硬设定到三章连贯正文，再到索引、校对表与可离线阅读的单文件网页。

**在线阅读：** https://wxb471.github.io/zhangbencheng/

## 这本书讲什么

账本城不用钱，只用「条目」：每写下一条，就必须划掉另一条。东街的记录员沈砚每天给公共账册换页，某天他发现昨日最后一格本该有条目，纸面却是空的——他袖口里那半片撕角旧纸，只剩半个「木」字。
